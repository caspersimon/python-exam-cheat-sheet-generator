| Call | Output example | Use |
|---|---|---|
| `'AbC'.lower()` | `'abc'` | all lower-case |
| `'AbC'.upper()` | `'ABC'` | all upper-case |
| `'abc'.islower()` | `True` | boolean test |
| `'ABC'.isupper()` | `True` | boolean test |
| `'aMSTERDAM'.capitalize()` | `'Amsterdam'` | first char upper, rest lower |
