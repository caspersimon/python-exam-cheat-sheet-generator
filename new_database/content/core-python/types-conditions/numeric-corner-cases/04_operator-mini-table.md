| Operator | Meaning | Example |
|---|---|---|
| `+` | addition / concatenation | `2 + 3`, `'a' + 'b'` |
| `-` | subtraction | `7 - 2` |
| `*` | multiplication / repetition | `3 * 4`, `'ha' * 2` |
| `**` | power | `2 ** 3` |
| `//` | floor division | `7 // 2` -> `3` |
| `%` | remainder | `7 % 2` -> `1` |
