# loc vs iloc

> [!summary] Summary
> Use `loc` for labels and `iloc` for integer positions. This single distinction solves many pandas MCQs.

> [!tip] Why this snippet matters
> The exams repeatedly mix DataFrames with row labels starting at 1 and positional indexing starting at 0.
