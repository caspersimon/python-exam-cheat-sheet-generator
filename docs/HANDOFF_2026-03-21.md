## Recommended Continuation Order

1. Run a quick dataset sanity check:

```bash
python3 - <<'PY'
import json
with open('topic_cards.json') as f:
    data = json.load(f)
cards = data['cards']
print('cards', len(cards))
print('deck_groups', len(data.get('deck_groups', [])))
print('weeks', sorted({w for c in cards for w in c.get('weeks', [])}))
print('exam_cards', sum(1 for c in cards if c['exam_stats']['total_hits'] > 0))
print('key_points', sum(len(c['sections'].get('key_points_to_remember', [])) for c in cards))
print('detail_blocks', sum(len(kp.get('details') or []) for c in cards for kp in c['sections'].get('key_points_to_remember', [])))
PY
```

2. Run validation in this order if you want to re-verify from scratch:

```bash
node --check app/*.js
python3 -m py_compile build_topic_cards.py generate_ai_sections.py generate_key_points_and_recommendations.py enrich_key_point_details.py
python3 -m py_compile $(find pipelines -name '*.py' -type f)
python3 scripts/check_file_lengths.py
python3 -m unittest discover -s tests -v
make smoke-ui
make full-ui
make stress-layout-ui
make leave-better-ui
```
