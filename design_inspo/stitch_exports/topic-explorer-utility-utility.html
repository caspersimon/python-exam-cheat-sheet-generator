Topic 4.2 Dictionary Operations

W4: Dictionary Membership and Slicing

Active Study Context

Data Structures & Logic

inventory Core Syntax & Key Points

Key In-Membership Check

Use the in keyword to check if a key exists in a dictionary (not values).

The .get() Safety Net

Retrieving values using dict.get(key) prevents KeyErrors.

Key Extraction

The keys() method returns a view object of all dictionary keys.

Mutable Slicing

Dictionaries don't support index slicing; use comprehensions for sub-sets.

code Essential Snippets 

user = {"id": 101, "role": "admin"}
# Check membership
if "role" in user:
    print(user["role"]) # Outputs: admin
# Dict Comprehension Slicing equivalent
raw = {"a": 1, "b": 2, "c": 3, "d": 4}
keys = ["a", "c"]
sliced = {k: raw[k] for k in keys if k in raw}

help_outline Common Questions

  • How to check if key NOT in dict?

    Use if key not in d:. It's more Pythonic than checking against d.keys().

  • Difference between .get() and dict[key]?

    .get() returns None if key doesn't exist; square brackets raise KeyError.

  • Are dictionaries ordered?

    As of Python 3.7+, dictionaries maintain insertion order as a language specification.

Quick Tip

When working with large datasets, using dict.fromkeys(list) is a highly performant way to initialize default maps.
