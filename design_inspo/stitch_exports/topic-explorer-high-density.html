Code Examples

Basic Membership

user = {"id": 1, "name": "JD"}
if "id" in user:
    print(user["id"])
# Output: 1

Dictionary Slicing

d = {'a':1, 'b':2, 'c':3}
ks = ['a', 'c']
res = {k: d[k] for k in ks}
# {'a': 1, 'c': 3}

Safe Get

val = d.get('z', 0)
# Returns 0 if 'z'
# is not in d

Common Questions

  • What is the time complexity of 'in'?

    Dictionary lookups are O(1) on average, making them significantly faster than list membership checks O(n).

  • Does 'in' work on nested keys?

    No, it only checks top-level keys. For nested structures, you must chain lookups or use recursive functions.

  • Can I slice with a range object?

    Dictionaries are unordered (pre-3.7) or insertion-ordered. Standard [start:stop] slicing does not work directly.

  • KeyError vs Membership?

    Using 'in' prevents KeyError exceptions entirely, which is cleaner than try-except blocks in many scenarios.

Exam Tip

Watch for questions that confuse .keys() with checking values. 'in' defaults to keys.
